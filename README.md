# 🤟 AI Sign Language Reader

An AI-powered real-time Sign Language Recognition System that helps bridge communication gaps for hearing-impaired individuals using Computer Vision, AI, and Speech Technologies.

## ✨ Features

* 🎥 Real-time Hand Gesture Recognition (30+ Gestures)
* 💬 Text-to-Gesture Conversion
* 🎤 Speech-to-Gesture Conversion
* 🔊 Voice Feedback System
* 📊 Analytics Dashboard
* 🎙️ Voice Command Navigation
* 🗄️ Gesture History Tracking
* ⚡ Fast Response Time with Cooldown System

## 🛠️ Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript (ES6)
* WebRTC
* Web Speech API
* Chart.js

### Backend

* Python
* Flask
* MediaPipe
* OpenCV
* NumPy
* MySQL
* pyttsx3

## 📈 Project Statistics

* 30+ Supported Gestures
* 350+ Supported Phrases
* 85–98% Detection Accuracy
* 12 REST API Endpoints
* Real-Time Processing

## 🚀 HOW TO DEPLOY ?

- Create two Folder like Frontend and Backend , add all 5 html files in Frontend Folder and Place it into Xammp if you want to use Database.
- Then add app.py | .json | .task to backend folder.
- run app.py and leave it running on cmd
- then run localhost/frontend/welcome.html on chrome if using xammp else run welcome.html directly on chrome.
- if you dont create xammp or db its okay just then history is not saving . 
- You can see app.py and create db and tables acc to it in you xammp/phpmyadmin using sql .
